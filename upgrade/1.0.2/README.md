# v1.0.2 版本说明（用于 Releases）

## 发布内容

1. 行程体验升级  
   行程轨迹展示更完整，轨迹数据同步能力增强，查看行程时信息更直观。

2. 权限与隐私收紧  
   访问日志按用户视角隔离，普通用户默认只看自己的数据，管理员可查看全局数据。

3. 稳定性优化  
   同步任务链路做了细化优化，异常场景下的记录和排查信息更清晰。

4. 账号能力增强  
   新增管理员/普通用户角色能力，为后续权限扩展打下基础。

## 升级提示

- 本版本包含数据库升级内容，发布时请执行同目录升级 SQL：  
  `upgrade/1.0.2/01_upgrade_1.0.1_to_1.0.2.sql`

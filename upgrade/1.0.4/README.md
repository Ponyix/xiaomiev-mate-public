## v1.0.4 版本说明

本次同步更新前端与后端，并已发布对应 Docker 镜像。

- 发布后端正式镜像：`ponyix/xiaomiev-mate:backend-v1.0.4`
- 发布前端正式镜像：`ponyix/xiaomiev-mate:web-v1.0.4`


## 发布内容

1. 新增足迹地图
   支持按行程时间展示全部路线、高频路线、起终点地图。
2. 自动获取用户车辆
   车辆管理->添加车辆获取该用户名下所有车辆。
3. 同步历史行程支持查看实时进度
   新用户在同步全部历史行程时，可以查看同步实时进度。
4. 事件订阅添加事件
   新增添加预警、智能通勤提醒。
5. 识别充电逻辑优化
6. 已知bug修复
